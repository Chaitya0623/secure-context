# Sharing the demo

The demo is `prototype/index.html`, a single file with no backend. All clients and population records in it are synthetic.

* **Locally:** open the file in a browser.
* **GitHub Pages:** Settings, then Pages, deploy from branch `main`, folder `/prototype` (needs admin on the repo).
* **Without hosting:** `https://raw.githack.com/Chaitya0623/secure-context/main/prototype/index.html` serves the file straight from GitHub.
